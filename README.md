# 🚀 حزمة مشاريع بايثون الاحترافية الـ 15 (Tkinter GUI Projects Suite)

مجموعة شاملة تضم **15 مشروع بايثون عملي متكامل** بواجهات رسومية احترافية مبنية بـ **Tkinter**، مقسمة حسب المستوى (مبتدئ، متوسط، متقدم)، حيث يحتوي كل مشروع على **مجلد مستقل، ملف تنفيذي منفصل، تصميم حديث، ومعمارية كود نظيفة (OOP)**.

---

## 🎛️ بوابة التشغيل السريعة (Master Launcher)

يمكنك تشغيل المنصة الرئيسية التي تمكنك من تصفح وتشغيل أي مشروع بنقرة زر واحدة عبر الأمر:

```bash
python3 launcher.py
```

أو تشغيل أي مشروع بشكل فردي ومستقل تماماً:

```bash
python3 <اسم_المجلد>/main.py
```

## 🌟 تفاصيل المشاريع الـ 15 والمميزات

### 🟢 المستوى المبتدئ (Projects 01 - 05)

1. **[01_advanced_calculator](file:///home/ibrahim-elshishtawy/flutter%20project/project_pyrthon/01_advanced_calculator/main.py)**:
   - حساب العمليات الأساسية، القوى ($x^y, x^2$)، الجذور ($\sqrt{x}$)، الدوال المثلثية (`sin`, `cos`, `tan`)، واللوغاريتمات والعاملي ($n!$).
   - شريط وسجل كامل للعمليات السابقة مع إمكانية استرجاع أي نتيجة بالنقر المزدوج.

2. **[02_number_guessing_game](file:///home/ibrahim-elshishtawy/flutter%20project/project_pyrthon/02_number_guessing_game/main.py)**:
   - 3 مستويات صعوبة (1-50، 1-100، 1-500) مع عداد للمحاولات المتبقية.
   - مؤشر حراري ذكي وتفاعلي (قريب جداً 🔥، بعيد ❄️، أعلى ⬆️، أقل ⬇️) وتسجيل لأفضل نتيجة قياسية في ملف JSON.

3. **[03_todo_manager](file:///home/ibrahim-elshishtawy/flutter%20project/project_pyrthon/03_todo_manager/main.py)**:
   - إضافة وحذف وتعديل المهام، وتحديد الأولوية (🔴 عالية، 🟡 متوسطة، 🟢 منخفضة) والقسم (عمل، دراسة، شخصي).
   - شريط بحث وفلاتر حالة مع بطاقة نسبة الإنجاز وحفظ تلقائي في ملف `tasks.json`.

4. **[04_password_generator](file:///home/ibrahim-elshishtawy/flutter%20project/project_pyrthon/04_password_generator/main.py)**:
   - تحديد دقيق لطول الكلمة وتخصيص الأحرف والأرقام والرموز مع استبعاد الأحرف المتشابهة.
   - شريط تفاعلي لحساب قوة التشفير والإنتروبيا وزر نسخ سريع للحافظة مع سجل محفوظ.

5. **[05_rock_paper_scissors](file:///home/ibrahim-elshishtawy/flutter%20project/project_pyrthon/05_rock_paper_scissors/main.py)**:
   - بطاقات تفاعلية كبيرة لرموز الأشكال مع عداد تشويقي للنتائج (3... 2... 1...).
   - لوحة إحصائيات تحسب فوز اللاعب، فوز الكمبيوتر، التعادل، نسبة الفوز المئوية، وسلسلة الانتصارات الحالية.

### 🟡 المستوى المتوسط (Projects 06 - 10)

6. **[06_expense_tracker](file:///home/ibrahim-elshishtawy/flutter%20project/project_pyrthon/06_expense_tracker/main.py)**:

8. **[08_telegram_bot_manager](file:///home/ibrahim-elshishtawy/flutter%20project/project_pyrthon/08_telegram_bot_manager/main.py)**:
   - يدعم التوصيل بتوكن بوت حقيقي أو تشغيل وضع المحاكي التفاعلي الفوري بدون توكن.

9. **[09_file_organizer](file:///home/ibrahim-elshishtawy/flutter%20project/project_pyrthon/09_file_organizer/main.py)**:
   - استعراض أي مجلد وتصنيف ملفاته تلقائياً (صور، مستندات، فيديوهات، صوتيات، أرشيفات، أكواد).
   - وضع المعاينة المسبقة (Dry Run) وميزة التراجع التلقائي (Undo) لإعادة الملفات لمكانها السابق.

10. **[10_url_shortener](file:///home/ibrahim-elshishtawy/flutter%20project/project_pyrthon/10_url_shortener/main.py)**:
    - تخزين الروابط في قاعدة بيانات SQLite محلية مع دعم أسماء الاختصار المخصصة.
    - خادم ويب محلي مدمج على المنفذ `8000` للتحويل الفعلي التلقائي عند فتح الرابط وحساب عدد النقرات لحظياً.
